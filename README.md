# Aplikasi CRUD Data Siswa (CentOS & PHP)

Aplikasi web sederhana berbasis PHP, MySQL (MariaDB), dan CentOS untuk mengelola data siswa. Didesain dengan antarmuka UI/UX modern bertema **Soft Pastel Glassmorphism**.

## Fitur Utama
- **Operasi CRUD** (Create, Read, Update, Delete).
- **Upload & Hapus Foto Profil** secara dinamis ke direktori server.
- **Keamanan Login Session** (MD5 Password).
- **UI Modern & Responsif** dengan efek Glassmorphism.
- Disiapkan untuk berjalan di atas **CentOS Web Server** (Apache).
